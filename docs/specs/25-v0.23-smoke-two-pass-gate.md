# 规格：Smoke 2 Pass Gate

> **阶段：**25 · **版本：**v0.23 · **状态：**已完成
>
> **前置阶段：**[阶段 24：Smoke 仅按通过数 Gate](24-v0.22-smoke-pass-count-only-gate.md)

## 目标

将完整五条 evaluation 的 Smoke gate 门槛从 `pass >= 3` 调整为 `pass >= 2`。

## 范围与约束

1. 两、三、四或五个 `pass` 都写入 v2 gate；零或一个 `pass`、或少于五条 evaluation 不写 gate。
2. 保留阶段 24 的仅按通过数语义：其他 verdict 与 run status 不额外拒绝 gate。
3. 新 receipt 记录 `minimum_passed_case_count=2`；历史 3/5 与 4/5 v2 receipt 保持可读、有效且不重写。
4. 不改变 Evolution/Final、custody、候选 binding、CLI 参数或真实运行；不运行 Docker、DSH、模型或评测集。

## 验收标准

1. 2/5 写入可验证的 v2 gate，1/5 不写 gate。
2. 历史 v2 3/5、4/5 receipt 继续认可；v1 receipt 仍拒绝。
3. 定向 pytest、Ruff、mypy 与 `git diff --check` 通过。
