# 规格：Smoke 1 Pass Gate

> **阶段：**26 · **版本：**v0.24 · **状态：**已完成
>
> **前置阶段：**[阶段 25：Smoke 2 Pass Gate](25-v0.23-smoke-two-pass-gate.md)

## 目标

将完整五条 evaluation 的 Smoke gate 门槛从 `pass >= 2` 调整为 `pass >= 1`。

## 范围与约束

1. 一个至五个 `pass` 写入 v2 gate；零个 `pass` 或少于五条 evaluation 不写 gate。
2. 保留仅按通过数规则：其他 verdict 与 run status 不额外拒绝 gate。
3. 新 receipt 记录门槛 1；历史 2/5、3/5、4/5 v2 receipt 保持可读有效且不重写。
4. 不改变 Evolution/Final、custody、候选 binding、CLI 或真实运行。

## 验收标准

1. 1/5 写入 v2 gate，0/5 不写 gate。
2. 历史 v2 2/5、3/5、4/5 receipt 继续认可；v1 仍拒绝。
3. 定向 pytest、Ruff、mypy 与 `git diff --check` 通过。
