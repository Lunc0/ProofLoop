# 实施计划：Optimizer Request Failure Codes

> **阶段：**27 · **版本：**v0.25 · **状态：**已完成

## 关联规格

[v0.25 规格](../specs/27-v0.25-optimizer-request-failure-codes.md)。

## 实施步骤

1. 在 optimizer 合同中扩展 error-code 枚举，保留历史 `request_failed`。
2. 让 DeepSeek 客户端把受控传输/HTTP/解析失败转为只携带固定 code 的异常。
3. advice 与 EditPlan 服务将该 code 写入 `model_failed` receipt；未知异常写 `unexpected_error`。
4. 为所有分类与历史兼容性编写定向测试，并更新操作文档。

## 检查点与风险

- 检查点：receipt 只含枚举 code，不含异常文本。
- 风险：HTTPError 是 URLError 子类；实现必须先处理 HTTP，再处理网络错误。
- 验证：`uv run pytest tests/test_optimizer_deepseek.py tests/test_optimizer_service.py tests/test_edit_plan_service.py`、Ruff、Mypy、`git diff --check`。
