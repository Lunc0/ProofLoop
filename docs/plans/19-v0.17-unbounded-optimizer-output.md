# 实施计划：Optimizer 无应用层输出上限

> **阶段：**19 · **版本：**v0.17 · **状态：**已完成
>
> **依据规格：**[阶段 19 v0.17 规格](../specs/19-v0.17-unbounded-optimizer-output.md)

## 实施方式

`max_output_tokens` 改为可选整数。为 `null` 时，DeepSeek payload 省略 `max_tokens`，两个依赖该值的本地响应字节检查也跳过；为整数时保留既有行为。

## 有序任务

1. 调整 `OptimizerConfig` 的类型与校验；保留正整数的显式配置路径。
2. 调整 `DeepSeekChatClient`、advice 和 EditPlan 的条件检查。
3. 添加配置和 client/service 的定向回归测试；执行静态与差异检查。
4. 更新 design 索引与实现记录，只写实际验证结果。

## 风险与验证

无上限只解除本项目限制，不绕过 provider 限制。响应仍视为不可信，失败时保留审计原文而不 materialize。
