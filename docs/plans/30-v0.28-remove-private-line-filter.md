# 实施计划：移除 Evolution 文本的私有结果整行过滤

> **阶段：**30 · **版本：**v0.28 · **状态：**已完成

## 关联规格

[阶段 30 规格](../specs/30-next-remove-private-line-filter.md)。

## 实施方案

将共享 `_safe_text()` 收窄为“凭据清洗 + 绝对路径清洗”，完全移除
`_PRIVATE_RESULT_LINE_PATTERN` 及整行替换。agent input 的 `evaluated_skill` 继续
表示实际发送文本的哈希；loader 继续验证 subject ID 和全部 artifact 完整性，但
不再将该发送文本或其哈希与原始 Candidate 内容进行相等比较。

## 任务与依赖

### Task 1：删除私有结果整行替换并覆盖误命中

**工作：**从 `compressor.py` 删除私有结果整行 pattern 与替换；补充/调整测试，
证明 “expected SQL” 这类普通安全指令保持原文，凭据与绝对路径仍然清洗。

**验收：**

- `_safe_text()` 不再产生 `<private-evaluator-material-redacted>`。
- Candidate Skill 中的 “expected SQL” 进入 agent input 时不被改写。
- 凭据和绝对路径现有回归仍通过。

**验证：**`uv run pytest tests/test_trajectory_compression.py tests/test_trajectory_projection.py`

**依赖：**无。

**文件：**`src/skill_evolve/trajectory/compressor.py`、
`tests/test_trajectory_compression.py`、`tests/test_trajectory_projection.py`。

### Task 2：移除原始 Skill 内容相等性校验

**工作：**从 `load_prepared_evolution_input()` 删除原始 Skill hash/text 的两项比较，
保留其余 fail-closed 检查；增加离线 service 测试，使用仍会被凭据清洗的 Skill
构造合法 canonical agent input 并确认 fake optimizer 被调用。

**验收：**

- 清洗后的 Skill 文本与原始 Candidate 不同不再造成 `skipped_invalid_evidence`。
- subject ID、payload/manifest hash、环境、投影版本、case count 与大小任一失配仍拒绝。

**验证：**`uv run pytest tests/test_optimizer_service.py`

**依赖：**Task 1。

**文件：**`src/skill_evolve/optimizer/evidence.py`、`tests/test_optimizer_service.py`。

### Checkpoint：离线行为与完整性边界

- [ ] Tasks 1–2 的定向 pytest 通过。
- [ ] 没有真实 DSH、模型、Docker、网络或 benchmark 调用。
- [ ] diff 中没有删除凭据、路径或剩余完整性校验。

### Task 3：最终验证与实现记录

**工作：**运行定向测试、Ruff、mypy 与 diff 检查；将规格/计划状态更新为已完成，
写入仅描述实际改动和验证结果的设计记录及索引。

**验收：**

- 代码和离线验证结果与规格一致。
- design 文档不把计划或未运行的真实评测写成事实。

**验证：**

```powershell
uv run pytest tests/test_trajectory_compression.py tests/test_trajectory_projection.py tests/test_optimizer_service.py
uv run ruff check src/skill_evolve/trajectory/compressor.py src/skill_evolve/optimizer/evidence.py tests/test_trajectory_compression.py tests/test_trajectory_projection.py tests/test_optimizer_service.py
uv run mypy src
git diff --check
```

**依赖：**Tasks 1–2。

## 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 真实 GT/Gold 词汇出现在文本中 | 保持其既有的结构化 artifact/custody 排除；本阶段只移除文字关键词整行替换。 |
| 删除内容校验扩大篡改面 | 保留 subject ID、canonical payload、manifest hash、环境、版本、case count、大小和路径安全校验。 |
| 清洗语义的回归误删凭据或路径防护 | 对 credential/path 与 expected-SQL 三类文本分别添加定向断言。 |

## 非并行项

Task 2 依赖 Task 1 的最终清洗语义；Task 3 在两者完成后执行。
