## 实际实现

`examples/sql-agent/dsh-no-web.patch.yml` 是一个 DSH `tool-web` 覆盖层，将 `search` 与 `fetch` 都设为
`false`。`examples/sql-agent/experiment.dsh.yaml` 通过 `environment.dsh.profile_patch` 引用该文件。

现有 manifest loader 将 `profile_patch` 解析并限制在 manifest workspace 内；现有 `DshRunner` 在
`--profile headless` 后传入该已解析路径。因此示例 benchmark 启动的 DSH 不会注册 `web_search` 或
`web_fetch`，且未修改用户的 `DSH_HOME`、provider route、settings 或 DSH 安装目录。

## 对外合同与安全边界

- `dsh.profile_patch` 是相对 manifest workspace 的已有文件；示例使用 `dsh-no-web.patch.yml`。
- `environment.tools` 仍不是 DSH runtime 工具 allowlist。
- 私有 Final manifest 不随 Git 分发；受信任 evaluator 必须在其受控 workspace 中复制并引用等价 patch。
- 此变更只移除 DSH 官方 web 工具。它不限制 `pwsh` 网络访问，也不阻止 agent 读取调用账户可读取的本机文件；
  OS ACL、独立执行身份和网络出口控制属于后续安全阶段。
