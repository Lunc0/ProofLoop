## 实际实现

`meets_smoke_gate_policy()` 现在仅要求完整五条 evaluation 且至少三个 `pass`；它不再按 run status 拒绝 gate。
因此完整 Smoke 的 timeout、`wrong_result`、`runner_invalid` 或 `evaluator_invalid` 会保留在结果证据中，但不会覆盖
通过数准入判断。少于五条 evaluation 的早停仍不能写 gate。

v2 gate receipt、历史 receipt、候选 binding、run status、Evolution/Final 与 custody 边界未改变。
