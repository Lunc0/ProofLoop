## 实际实现

当前 Smoke gate 最低通过数为 3。完整五题、无基础设施无效且 3、4 或 5 个 `passed` 时，运行器写入 v2 receipt，
其中 `minimum_passed_case_count=3`。3/5 与 4/5 的整体 run status 保持 `task_failure`；gate 仅是是否可运行
Evolution 的准入证明。

v2 receipt 的读取兼容最低通过数为 3 或 4：既有 4/5 receipt 未被改写且继续有效，因为它满足更严格的历史门槛；
v1 receipt 仍只可审计、不能放行。v2 receipt 无论其写入时门槛为何，都必须有至少 3 个通过，且不得少于其记录的
最低通过数。

当前操作手册已更新为 3/5。Smoke 配额继续为 Simple 3、Moderate 2、Challenging 0；Evolution、Final、custody
边界、CLI 与 optimizer 合同未改变。
