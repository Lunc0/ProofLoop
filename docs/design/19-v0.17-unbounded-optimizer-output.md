# 实现记录：Optimizer 无应用层输出上限

> **阶段：**19 · **版本：**v0.17 · **状态：**已完成
>
> **规格：**[阶段 19 v0.17 规格](../specs/19-v0.17-unbounded-optimizer-output.md) · **计划：**[实施计划](../plans/19-v0.17-unbounded-optimizer-output.md)

## 实际实现

`OptimizerConfig.max_output_tokens` 现为可选正整数，默认 `null`。未设置时，DeepSeek request 省略 `max_tokens`，client、advice 与 EditPlan 不再执行依赖 token 限制的本地响应字节检查。显式整数仍保留原有 request 字段与检查。

这不绕过 DeepSeek 的 provider 限制、timeout 或计费，也不改变输入上限、凭据处理、轨迹投影或 EditPlan 的 JSON/schema/binding 校验。

## 验证

离线定向验证通过：`32 passed`（optimizer DeepSeek、advice、EditPlan、配置测试）；`uv run ruff check src tests` 与 `uv run mypy src` 通过；`git diff --check` 通过。未调用真实 provider、DSH、Docker 或完整评测。
