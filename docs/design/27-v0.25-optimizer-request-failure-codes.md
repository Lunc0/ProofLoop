# 实现记录：Optimizer Request Failure Codes

> **阶段：**27 · **版本：**v0.25 · **状态：**已完成

## 实际实现

DeepSeek optimizer client 将请求层失败转为固定 error code：`request_timeout`、`network_error`、
`http_4xx`、`http_5xx`、`http_other`、`provider_response_invalid` 与 `response_limit_exceeded`。
advice 和 EditPlan 服务把该 code 写入 `model_failed` receipt；直接抛出的 timeout/OSError 分别映射为
`request_timeout`/`network_error`，未知异常映射为 `unexpected_error`。

## 合同与兼容性

两种 receipt 使用同一 error-code 枚举。历史 `request_failed` 仍被接受；新请求不再写该笼统 code。
不会写入具体 HTTP status、异常消息、URL、HTTP body、模型原文、prompt、题目、session 或凭据。

## 验证

已用假 HTTP transport 覆盖状态类别、timeout、网络错误、HTTPError、provider envelope 无效和输出超限；
advice/EditPlan 覆盖安全 receipt 分类与异常文本不落盘。
