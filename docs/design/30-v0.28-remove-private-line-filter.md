# 实现记录：移除 Evolution 文本的私有结果整行过滤

> **阶段：**30 · **版本：**v0.28 · **状态：**已完成

## 实际实现

`trajectory.compressor._safe_text()` 不再根据 `gold`、`gt`、`expected` 与
`sql`、`query`、`result` 的组合替换整行文本。因此 Candidate Skill 中“不得从
private material 推断 expected SQL 或 result”的安全指令会原样进入 Evolution
agent input，不再被误替换为私有评测材料占位符。

凭据与绝对路径清洗未改变：credential-shaped assignment、Bearer token、`sk-`/
`ds-` 样式密钥仍替换为 `<redacted>`；受支持的 Windows 和 Unix 绝对路径仍替换为
`<absolute-path>`。结构化 projection 原有的 GT/Gold、原始 evaluator 结果、内部
reasoning 和 custody metadata 排除也未改变。

`optimizer.evidence.load_prepared_evolution_input()` 保留 subject ID、canonical
payload/manifest hash、输入大小、环境指纹、projection rule version、trajectory
数量和路径安全检查。它不再把清洗后的 `payload.skill` 或其
`evaluated_skill.content_sha256` 与原始 Candidate 内容逐字节比较；Advice receipt
继续使用原始 Candidate SHA-256 作为谱系绑定。
